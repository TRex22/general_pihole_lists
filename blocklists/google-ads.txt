# Google Ads Blocklist for Pi-hole
# Hand-curated Google ad-serving / ad-measurement hosts. Several of these are
# missing from the generated uBlock/Privacy Badger lists because the upstream
# filter rules for them carry $options (third-party, script) that a DNS list
# cannot express, so they are listed here explicitly.
# Not included: imasdk.googleapis.com (Google IMA video SDK — blocking it breaks
# many embedded video players; uBlock's unbreak list deliberately allows it).
